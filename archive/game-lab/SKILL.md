# SKILL.md

## Purpose
Interactive browser game and experimentation laboratory used as a public demonstration of frontend interaction, game logic and visual engineering.

## Skills demonstrated
- Browser-based interaction
- JavaScript state and event handling
- UI/UX experimentation
- Lightweight game mechanics
- Visual presentation

## Public/private boundary
This repository is intended for public demonstrations. Private application logic, research assets and non-public intellectual property must remain outside this repository.
