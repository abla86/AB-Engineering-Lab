# Learning Path

## AB Engineering Lab

The projects are organised as a progressive engineering path. The objective is to show how individual technical skills develop toward larger software systems.

## 01 — Web fundamentals

### Hello HTML

Focus:

- HTML structure
- semantic elements
- basic CSS
- browser rendering
- file organisation

This establishes the web foundation used by the later projects.

## 02 — JavaScript and browser logic

### Calculator

Focus:

- JavaScript
- functions
- events
- DOM manipulation
- user input
- application logic

### Digital Clock

Focus:

- browser APIs
- time
- dynamic rendering
- repeated execution

### JavaScript Counter

Focus:

- state changes
- events
- DOM updates

### Advanced JavaScript Counter

Focus:

- structured JavaScript behaviour
- application state
- reusable logic
- interaction

## 03 — Application development

### Todo Application

Focus:

- modular JavaScript
- application state
- persistence
- UI separation
- automated tests

### Task Manager

Focus:

- task-oriented UI
- application behaviour
- state and interaction
- structured frontend code

## 04 — React

### React Task Dashboard

Focus:

- React components
- component composition
- props
- state
- Vite
- modern frontend development

This stage represents the transition from direct DOM manipulation to component-based UI architecture.

## 05 — Backend

### FastAPI Learning

Focus:

- Python
- FastAPI
- REST-style HTTP endpoints
- Pydantic models
- SQLAlchemy
- database persistence
- CRUD
- backend testing

This introduces server-side development and persistent data.

## 06 — Full-stack integration

The next stage is to combine the previous frontend and backend work through an explicit API boundary.

Target:

```text
React
  ↓
API client
  ↓
FastAPI
  ↓
Application logic
  ↓
Database
```

Stage 06 should only be considered implemented when the integration is actually built and tested.

## Overall progression

```text
WEB
 ↓
PROGRAMMING LOGIC
 ↓
APPLICATIONS
 ↓
COMPONENT ARCHITECTURE
 ↓
BACKEND SERVICES
 ↓
DATA PERSISTENCE
 ↓
FULL-STACK INTEGRATION
 ↓
AUTOMATED DELIVERY
```

The progression documents development work and engineering direction without treating planned capabilities as completed features.
