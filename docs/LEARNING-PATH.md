# Learning Path

## AB Engineering Lab

The projects form a progressive engineering path. The sequence shows how individual technical skills can develop toward larger software systems.

## 01 — Web fundamentals

### Hello HTML

Focus:

- HTML structure
- semantic elements
- basic CSS
- browser rendering

## 02 — JavaScript and browser logic

### Calculator

Focus:

- JavaScript
- functions
- events
- DOM manipulation
- user input
- application logic

### Digital Clock

Focus:

- browser APIs
- time
- dynamic rendering
- repeated execution

### JavaScript Counter

Focus:

- state changes
- events
- DOM updates

### Advanced JavaScript Counter

Focus:

- structured JavaScript behaviour
- application state
- reusable logic
- interaction

## 03 — Application development

### Todo Application

Focus:

- modular JavaScript
- application state
- persistence
- UI handling
- automated tests

### Task Manager

Focus:

- task-oriented UI
- application behaviour
- state and interaction
- structured frontend code

## 04 — React

### React Task Dashboard

Focus:

- React components
- component composition
- props
- state
- Vite
- frontend architecture

This stage represents the transition from direct DOM manipulation to component-based UI development.

## 05 — Backend

### FastAPI Learning

Focus:

- Python
- FastAPI
- REST-style HTTP endpoints
- Pydantic models
- SQLAlchemy
- database persistence
- CRUD
- backend testing

This introduces server-side services and persistent data.

## 06 — Full-stack integration

The next stage is to connect the frontend and backend through an explicit API boundary.

Target:

```text
React
  ↓
API client
  ↓
FastAPI
  ↓
Application logic
  ↓
Database
```

Stage 06 is only complete when the integration is implemented and tested.

## Overall progression

```text
WEB
 ↓
PROGRAMMING LOGIC
 ↓
APPLICATIONS
 ↓
COMPONENT ARCHITECTURE
 ↓
BACKEND SERVICES
 ↓
DATA PERSISTENCE
 ↓
FULL-STACK INTEGRATION
 ↓
AUTOMATED DELIVERY
```

The progression documents completed work and engineering direction without presenting planned capabilities as completed features.
