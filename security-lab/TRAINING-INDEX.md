## Existing implementations

The curriculum deliberately reuses existing work:

- `CodeSentinel` — GitHub App and CI/security engineering
- `WPWW-WarRoom---Elite-Defense-Honeypot` — honeypot and defensive security concepts
- `agenttrace` — bounded AI-agent security scenarios
- `HealthTechDeviceApi` — API and healthcare security
- `azure-kubernetes-showcase` — Azure, Kubernetes, containers and CI/CD
- `developer-portfolio` — public presentation

## Training contract

Every practical exercise must have an explicit scope, synthetic/local data, a defensive counterpart and verification evidence.

The lab defaults to local/isolated execution and must not be used against systems without explicit authorization.
