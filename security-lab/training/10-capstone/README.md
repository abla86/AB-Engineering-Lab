# Capstone

End-to-end local scenario: vulnerability, controlled test, detection, incident response, remediation and verification.

## Status

Module scaffold. Build it incrementally from the canonical training program.

## Required progression

`LEARN -> UNDERSTAND -> LAB -> INVESTIGATE -> DETECT -> DEFEND -> REMEDIATE -> VERIFY`

## Required artifacts

- OBJECTIVES.md
- THREAT-MODEL.md
- LAB.md
- DEFENSE.md
- VERIFICATION.md
- tests/
- fixtures/ when required
- solution/ when useful

## Safety

Use only local, synthetic and isolated training targets. Do not use real credentials, personal data, production systems or third-party targets.

## Definition of done

The module needs executable evidence, automated verification and documentation before it is marked complete.
