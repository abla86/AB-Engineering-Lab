# Security research baseline

The cyber range is informed by current public security frameworks and guidance:

- OWASP Top 10:2025 — application security risk taxonomy.
- OWASP ASVS 5.0.0 — application security verification requirements.
- NIST SP 800-218 SSDF — secure software development practices.
- MITRE ATT&CK Enterprise — adversary tactics and techniques.
- MITRE D3FEND — defensive countermeasure knowledge graph.
- CISA Secure by Design — product security ownership, transparency and secure defaults.

The repository does not claim that these frameworks enumerate every possible attack. They are used as structured baselines that are periodically reviewed.

## How the range uses them

OWASP → application vulnerability scenarios and secure coding controls.

ATT&CK → red-side scenario taxonomy and event modeling.

D3FEND → blue-side countermeasure vocabulary and layered defense design.

NIST SSDF → CI, verification, dependency and secure-development controls.

CISA Secure by Design → security-by-default and product-security principles.

The executable implementation remains synthetic and local-only.
