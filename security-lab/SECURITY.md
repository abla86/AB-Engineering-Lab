# Security Policy — Application Security Lab

This directory is intentionally designed for security education.

## Safe-use boundary

- Run the lab only on `127.0.0.1` or another isolated environment you control.
- The vulnerable examples are deliberately insecure and must never be deployed as production code.
- Do not point the examples, tests or proof-of-concept requests at systems you do not own or have explicit permission to assess.
- Do not add real credentials, tokens, patient information, private data or production connection strings.

## Reporting

This lab contains intentional vulnerabilities. Real security findings in other projects should be reported privately to the repository owner rather than disclosed through public issues.
