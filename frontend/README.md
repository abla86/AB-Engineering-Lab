# AB Engineering Lab — Frontend

The unified interactive frontend for AB Engineering Lab.

It presents the original learning projects as one coherent engineering system and provides:

- project explorer
- live browser labs for standalone HTML/JavaScript exercises
- source views for React and backend modules
- technology matrix
- system architecture
- development evolution
- responsive UI

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
