# Task Manager

Responsive task-management application built with vanilla JavaScript.

## Features

- Create, edit and delete tasks
- Completion state and active/completed filtering
- Task priorities and due dates
- Search and task statistics
- Persistent state using localStorage
- Light and dark themes
- Responsive interface

## Technology

- HTML5
- CSS3
- JavaScript
- Web Storage API
- Git / GitHub
- GitHub Pages

## Live demo

https://abla86.github.io/task-manager/

## Purpose

Demonstrates practical frontend development with DOM manipulation, CRUD-style operations, browser persistence, state management and responsive UI design.
