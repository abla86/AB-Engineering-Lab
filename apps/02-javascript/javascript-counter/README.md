# JavaScript Counter

A small browser application demonstrating DOM manipulation, event handling and basic state management with vanilla JavaScript.

## Features

- Increase and decrease the counter
- Dynamic DOM updates
- Separate HTML, CSS and JavaScript files
- Simple responsive presentation

## Technology

- HTML5
- CSS3
- JavaScript
- DOM API

## Run locally

Open `index.html` in a modern browser.

## Purpose

This is an early JavaScript learning project and forms part of the development progression shown in my portfolio. It is intentionally small and dependency-free.
