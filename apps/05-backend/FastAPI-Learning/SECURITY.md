# Security Policy

## Scope

This repository is a learning project and does not process real patient, personal health, or other sensitive production data.

## Reporting a vulnerability

Please do not disclose security issues publicly. Report suspected vulnerabilities privately through GitHub's repository security reporting features when available.

## Security expectations

- Never commit credentials, API keys, tokens, patient data, or other secrets.
- Keep dependencies updated.
- Treat example data as synthetic.
- Do not interpret this repository as production-ready healthcare infrastructure.
