# Hello HTML

A minimal HTML5 learning project demonstrating the basic structure of a web page.

## Purpose

This is an introductory project in the development progression behind my portfolio. It demonstrates semantic HTML structure and the fundamentals of creating a browser-rendered page.

## Technology

- HTML5

## Run locally

Open `index.html` in a modern web browser.

## Scope

Learning project. No external dependencies and no backend.
