# Technology lab

Small, independently verified showcases of individual technologies. Each has its own tests and a CI job (`.github/workflows/technology-lab.yml`).

| Showcase | Technology | What it demonstrates |
|---|---|---|
| [`nextjs-showcase`](nextjs-showcase) | Next.js 15 / TypeScript | App Router, React Server Component, typed route handler, Vitest |
| [`java-showcase`](java-showcase) | Java 21 / Maven | records, streams, JUnit 5 |
| [`kotlin-showcase`](kotlin-showcase) | Kotlin / Gradle | data classes, `require` validation, kotlin.test |
| Python / FastAPI | Python | see [`apps/05-backend/FastAPI-Learning`](../apps/05-backend/FastAPI-Learning) (Pydantic validation, health endpoint, pytest) |
| Go, Java and Kotlin Kafka consumers | Go / Java / Kotlin | see [`projects/eventforge/consumers`](../projects/eventforge/consumers) |
