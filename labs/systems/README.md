# Systems Lab

Reusable browser-native systems experiments consolidated from the former `abla86/systems-lab` repo (now `archive/systems-lab`).

## Engines

- `wasm-benchmark.js` — in-memory WebAssembly instantiation and measured JavaScript/WebAssembly comparison with result-integrity verification.
- `worker-pool.js` — bounded native Web Worker pool with lifecycle telemetry, completion tracking and deterministic cleanup.

These modules are browser-native demonstrations. They do not depend on external services or backend infrastructure.
