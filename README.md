# FastAPI Learning

Et enkelt læringsprosjekt med FastAPI.

## Kjør lokalt

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload
```

## Endepunkter

- `/`
- `/health`
- `/hello/{name}`
- `/docs`
